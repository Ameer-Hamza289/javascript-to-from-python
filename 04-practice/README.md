# Practice

Same problems in both languages. Solve in the language you're **learning**. Peek at the other file only if stuck — comparing solutions is part of the learning.

## How to practice
1. Read the prompt in `prompts.md`.
2. Open the stub for your target language (`ex01/js.js` or `ex01/py.py`).
3. Implement until the checks at the bottom print OK.
4. Optionally implement the other language too — teaching both directions locks concepts in.

## Exercises

| # | Topic | Skills |
|---|-------|--------|
| 01 | Grade totals | variables, functions, collections |
| 02 | Grade report | strings, control flow, maps/dicts |
| 03 | Unique words | loops, sets, string methods |
| 04 | Mini bank | classes, encapsulation, errors |
| 05 | Shape areas | inheritance / duck typing |
